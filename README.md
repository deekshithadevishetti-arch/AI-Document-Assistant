# 🤖 AI Document Assistant

AI Document Assistant is an AI-powered document question-answering application that allows users to upload documents and interact with their content using natural-language questions.

The application uses **Retrieval-Augmented Generation (RAG)** to extract information from documents, split the content into smaller chunks, generate embeddings, store them in a vector database, and retrieve the most relevant information to answer user questions.

## 🚀 Features

- 📄 Upload and process documents
- 🔍 Extract text from uploaded documents
- ✂️ Split documents into smaller text chunks
- 🧠 Generate embeddings for document content
- 🗃️ Store document embeddings in a vector database
- 🔎 Perform semantic search
- 💬 Ask questions about uploaded documents
- 🤖 Generate AI-powered answers
- ⚡ Simple and interactive Streamlit interface

## 🛠️ Technologies Used

- **Python**
- **Streamlit**
- **Retrieval-Augmented Generation (RAG)**
- **Large Language Model (LLM)**
- **Text Embeddings**
- **Vector Database**
- **Document Processing**
